## Todo_list_python
a simple python program that allows users add their tasks.

## Features
allows users add a task
saves task in a databse
allows users see tasks
persists data storage using SQlite

## Technologies used
python 
SQlite

## How to run 
Make sure Python is installed
Clone or download this repository
Open the project folder in your terminal
Run the Python program:
python to-do list.py
